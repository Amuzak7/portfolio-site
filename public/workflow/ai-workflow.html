INPUT

STAGE / 02

PROCESS

Markdownルール × Claude

Markdownで定義したルール・テンプレートをClaudeに参照させ、HTML／Mermaidを使った見やすい資料を生成させます。ルールがあるから、出力が安定します。

Claude rules.md template.md prompt

OUTPUT

経営層・現場・PDF前提の3パターン。Tailwind CSSとMermaidを活用した、1ファイルで完結するモダンな資料が出力されます。

.html Tailwind Mermaid PDF-ready
03 / FEATURES

仕組みを支える4つの特徴

Markdownで定義する運用ルール

「PDF前提のときはアコーディオン禁止」「経営層には青基調」など、運用ルールをMarkdownで明文化。チームでメンテナンスでき、AIにも人間にも読めるドキュメントになります。

PDF化を前提とした設計

A4の余白、改ページ制御、印刷時のスタイル切替を組み込み済み。ブラウザの「PDFとして保存」だけで配布物が完成します。

HTML × Mermaidで視覚化

業務フローや構造図はMermaidで記述。テキストベースなのでAIが直接生成でき、後の修正もコードの差分で管理できます。

対象者別のチューニング

経営層には「全体像と投資対効果」、現場には「具体的な負担と打ち手」。トーンと深さをテンプレート側で切り替えます。

04 / UNDER THE HOOD

舞台裏 — Markdownで全部書く

HTML資料作成ルール.md 
# HTML資料作成ルール

## 基本方針
- 資料は 1つのHTMLファイル で完結させる
- Tailwind CSS CDN を使用
- 印刷（PDF化）を前提に作成する
- 対象者に応じて深さと表現を変える

## HTMLとMermaidの使い分け
- 業務フロー・全体像 → Mermaid
- ヒートマップ・比較表 → HTMLテーブル
- 詳細説明 → HTML（PDF時は展開）

## PDF化を前提とする場合
- アコーディオン・トグルは 使用しない
- 全内容を最初から展開した状態で作成
- 改ページとフォントサイズを意識
経営層向け_業務フロー説明.md 
# 経営層向け業務フロー説明資料

## 参照するルール
HTML資料作成ルール.md を遵守

## 入力
- 議事録（Markdown）

## 出力要件
1. エグゼクティブサマリー
2. 業務フロー（Mermaid）
3. 負担ヒートマップ
4. 問題点の詳細
5. 改善提案（優先度色分け）
6. 次の一手

## 指示
→ ルールに従い、1ファイルのHTMLを生成

Claudeにチャットで「このルールとテンプレを参照して、議事録から資料を作って」と頼むだけ。
人間が触るのはMarkdownだけで、HTMLは全てAIが書く。
